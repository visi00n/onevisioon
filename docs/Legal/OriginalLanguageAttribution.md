# Original Language Attribution

One Visioon includes an original-language study layer for the Bible.

## Greek Old Testament Text

- Source: CenterBLC LXX TextFabric dataset, based on the LXX-Rahlfs-1935 project
- Repository: https://github.com/CenterBLC/LXX
- License: MIT for the CenterBLC repository materials; underlying source attribution follows the repository notes.

## Greek New Testament Text

- Source: SBL Greek New Testament
- Repository: https://github.com/Faithlife/SBLGNT
- License: Creative Commons Attribution 4.0 International
- Copyright: Society of Biblical Literature and Logos Bible Software

## Greek Word Study Data

- Source: Open Greek New Testament Project
- Repository: https://github.com/eliranwong/OpenGNT
- License: Creative Commons Attribution-ShareAlike 4.0 International

The in-app word glosses are study aids. They should be read in context and should not be treated as one-to-one replacements for a full Bible translation.
